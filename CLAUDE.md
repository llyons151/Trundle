# Hard rule: no glow unless the user explicitly asks

Never add glow effects on your own initiative: no colored/tinted shadows, no outer
glows, no neon, bloom, halos, blurred light bands or "glow" images. Neutral drop
shadows for elevation are fine; a shadow tinted with a brand/accent color is a glow.

**Exception:** a glow is allowed only when the user explicitly asks for that
specific glow (e.g. "add a glow behind the moon"). Keep it to exactly what was
asked, and don't extend it to other screens or components. A general request
("make it prettier", "more atmospheric") is not permission. Glows the user has
explicitly approved stay; don't remove them by citing this rule.
